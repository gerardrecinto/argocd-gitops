Break a release and watch the check catch it

The repo ships scripts/check_refs.py, which runs in CI to verify the team deployment model. It runs here unchanged against the repo's real files in an in-memory copy. Edit anything, or use a preset that makes a classic mistake, then run the check. Nothing is saved or sent.

The team deployment model

Three teams ship through three environments from one repo. A release is a pinned list of image tags, and an environment is a pointer to a release.

EnvSyncHow a change lands
devautomated, prune, self-healMerge a change to envs/dev.yaml
stageautomated, prune, self-healReviewed PR to envs/stage.yaml, CODEOWNERS is the gate
prodmanualReviewed PR to envs/prod.yaml, then a release manager syncs
1

Releases are immutable

Tags must be sha-<40 hex> or vX.Y.Z, never latest. To change what runs, add a new release file and point an env at it.

2

Projects fence each team

Each AppProject allows only its own repo and per-env namespaces, and no cluster-scoped resources. Roles split deploying to dev from releasing to stage and prod.

3

One hardened chart

Every service renders from the same Helm chart, so a security fix lands once for all of them.

Use the patterns

All cluster names, registries and hostnames in the repo are PLACEHOLDER_* values. Swap in your own before applying anything.

argocd cluster add <dev-context>   --name dev
argocd cluster add <stage-context> --name stage
argocd cluster add <prod-context>  --name prod
argocd proj create -f bootstrap/project.yaml
argocd app create -f bootstrap/root.yaml
pip install pyyaml
python3 scripts/check_refs.py
argocd app list -l team=backend

The platform and frontend releases use synthetic example tags. items-api is the real image from gitops-aks-demo.

What this does not do
  • It is a set of reference patterns, not a live cluster. Nothing here syncs to a real control plane.
  • The check validates structure and pins. It does not prove a release is safe to run.
  • This page runs the checker on an in-memory copy of the files. It never talks to Argo CD or Kubernetes.
